# Assignment 39: GenAI App Deployment

#Name- Prerana Khamkar

## Introduction

This project demonstrates the deployment of a Generative AI
application using Streamlit Cloud and Hugging Face Spaces.

The application acts as an AI Coding Assistant that can
generate code, explain code, debug errors, and suggest
code improvements.

## Technologies Used

- Python
- Streamlit
- Groq API
- GitHub
- Streamlit Cloud
- Hugging Face Spaces

## Features

1. Code generation
2. Code explanation
3. Code debugging
4. Code optimization suggestions

## Installation

Install the required libraries:

pip install -r requirements.txt

## API Configuration

The application requires a GROQ_API_KEY.

Configure the key using the secrets settings of the
deployment platform. Do not upload API keys to GitHub.

## Run Locally

Run the following command:

streamlit run app.py

## Deployment

The application can be deployed on Streamlit Cloud
and Hugging Face Spaces.

## Conclusion

This assignment helped me understand how to deploy a Generative AI application and make it accessible through a web browser. I also learned about dependency management, API key configuration, and the differences between deployment platforms.
